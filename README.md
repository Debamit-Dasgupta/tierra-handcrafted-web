6. TEXTURE

==================================================

Texture is essential.

Flat digital color alone will make this look like a generic website.

Use extremely subtle textures:

- Wood grain

- Kraft paper

- Recycled paper

- Plaster

- Slight grain/noise

Texture opacity should remain subtle, approximately 5–8%.

Never make texture interfere with readability.

Texture should feel physical rather than like a filter.

Use texture particularly on:

- Pine-colored blocks

- Menu section

- Editorial dividers

- Footer

- Small graphic panels
